## Избранные проекты

### [RepoScope](https://github.com/F0REST1R/RepoScope)

Сервис поиска и экспресс-оценки публичных GitHub-репозиториев с объяснимым Repo Health Score, избранным и адаптивным интерфейсом.

`Go` `chi` `PostgreSQL` `React` `TypeScript` `GitHub API` `OpenAPI` `Docker Compose`

- слоистый backend и интеграция с GitHub REST API;
- кэширование, middleware, graceful shutdown и единый формат ошибок;
- unit- и integration-тесты, CI, OpenAPI, Postman и cURL-сценарии.

### [VPSDeck](https://github.com/F0REST1R/VPSDeck)

Настольное приложение для учета VPS и выделенных серверов, проверки доступности, SSH-синхронизации и просмотра системных метрик.

`Go` `Wails` `React` `TypeScript` `SSH` `Vitest`

- архитектура ports and adapters;
- TCP-проверки и сбор метрик Linux-серверов по SSH;
- безопасное хранение паролей в Windows Credential Manager и атомарная запись данных.

### [DNS Resolver API](https://github.com/F0REST1R/DNS-resolver)

Backend-сервис для хранения, обновления и обратного поиска соответствий между FQDN и IP-адресами.

`Go` `Echo` `PostgreSQL` `GORM` `OpenAPI` `testify` `Docker Compose`

- REST API с валидацией и разделением HTTP-, бизнес- и data-логики;
- фоновое обновление DNS-записей с `context` и корректным завершением;
- тесты обработчиков и репозитория, документированный API и воспроизводимый запуск.
